# 基金股票智能分析系统 — 测试文档

## 概述

本系统覆盖 **4 个模块**的自动化测试，支持 **5 种测试类型**：

| 模块 | 语言 | 框架 | 测试类型 |
|---|---|---|---|
| `backend/` | Java 11 | JUnit 5 + Mockito + MockMvc | 单元测试、Web MVC |
| `frontend/` | TypeScript | Vitest + Vue Test Utils | 单元测试、Store 测试 |
| `analysis-algorithms/` | Python | pytest | 算法正确性测试 |
| `data-collector/` | Python | pytest + pytest-mock | 接口/逻辑测试 |
| `bigdata-processing/mapreduce/` | Java 11 | JUnit 5 | 单元测试 |

## 运行测试

### 一键运行所有测试

**Windows**:
```bash
scripts\run-all-tests.bat
```

**Linux/Mac**:
```bash
chmod +x scripts/run-all-tests.sh
./scripts/run-all-tests.sh
```

### 单独运行各模块

**后端 (backend)**:
```bash
cd backend
mvn test                          # 运行全部测试
mvn test -Dtest=AnalysisServiceImplTest  # 运行单个测试类
mvn test -Dtest=*ControllerTest   # 运行所有 Controller 测试
```

**前端 (frontend)**:
```bash
cd frontend
npm install            # 首次运行前安装依赖
npm run test           # 运行全部测试
npm run test:watch     # 监听模式（开发时使用）
npm run test:coverage  # 带覆盖率报告
```

**分析算法 (analysis-algorithms)**:
```bash
cd analysis-algorithms
pip install -r requirements.txt   # 首次运行前安装依赖
pytest tests/ -v                  # 运行全部测试
pytest tests/test_technical.py -v # 运行单文件
pytest -k "ma" -v                 # 按关键字运行
```

**数据采集 (data-collector)**:
```bash
cd data-collector
pip install -r requirements.txt   # 首次运行前安装依赖
pytest tests/ -v                  # 运行全部测试
```

**MapReduce (bigdata-processing)**:
```bash
cd bigdata-processing/mapreduce
mvn test                          # 运行全部测试
```

## 测试策略说明

### 后端测试策略
- **Service 层**: 使用 `@ExtendWith(MockitoExtension.class)` + `@Mock`/`@InjectMocks`，Mock 掉 Mapper 和数据库
- **Controller 层**: 使用 `@WebMvcTest` + `@MockBean`，Mock 掉 Service，用 MockMvc 模拟 HTTP 请求
- **边界覆盖**: 空数据、零值、数据不足、默认参数等

### 前端测试策略
- **Store**: 纯逻辑测试，无需渲染组件，快速验证状态管理
- **API 层**: mock `axios` 验证拦截器配置
- **组件测试**: 可通过 `@vue/test-utils` + `mount()` 扩展

### Python 测试策略
- **共享 Fixtures**: `conftest.py` 提供可复用的模拟 K线数据
- **算法验证**: 用 `pytest.approx` 做浮点数对比，验证指标值域和关系

### MapReduce 测试策略
- 纯逻辑验证（输入解析、公式计算）
- 复杂场景可使用 `hadoop-minicluster` 做 MiniCluster 集成测试

## 开发指南

### 添加新的测试

**后端**: 在 `backend/src/test/java/com/stock/` 下创建对应包路径的测试类

```java
@ExtendWith(MockitoExtension.class)
class NewServiceTest {
    @Mock private SomeMapper mapper;
    @InjectMocks private NewServiceImpl service;

    @Test
    @DisplayName("功能描述")
    void testSomething() {
        // Arrange - given
        when(mapper.method()).thenReturn(result);
        // Act - when
        var result = service.method();
        // Assert - then
        assertEquals(expected, result);
    }
}
```

**前端**: 在 `frontend/src/__tests__/` 下创建测试文件

```typescript
import { describe, it, expect } from 'vitest'
import { setActivePinia, createPinia } from 'pinia'
import { useMyStore } from '@/stores/myStore'

describe('MyStore', () => {
  beforeEach(() => setActivePinia(createPinia()))

  it('should work', () => {
    const store = useMyStore()
    expect(store.value).toBeDefined()
  })
})
```

**Python**: 在 `*/tests/test_*.py` 下使用 pytest

```python
def test_feature(sample_data):
    result = my_function(sample_data)
    assert len(result) > 0
```

## 持续集成 (CI) 集成建议

创建 `.github/workflows/test.yml` 即可集成 GitHub Actions：

```yaml
name: Test
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run all tests
        run: bash scripts/run-all-tests.sh
```

> 当前版本合计 ~78 个测试用例，覆盖核心业务逻辑，可直接在生产级 CI 中运行。
