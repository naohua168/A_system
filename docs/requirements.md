## 1. 项目概述

### 1.1 项目定位

构建一个覆盖"数据采集 → 大数据处理 → 算法分析 → 后端 API → 前端展示 → AI 智能对话"全链路的金融智能分析平台。为投资者提供实时行情监控、技术指标计算、缠论分析、量化回测、多智能体 AI 深度分析的综合解决方案。

### 1.2 项目目标

1. **数据采集自动化**：从多个外部数据源自动采集 A 股实时行情、资金流向、龙虎榜、基金净值等金融数据。 **✅ 已完成**
2. **大数据存储与计算**：基于 Hadoop 生态（HDFS + Hive + Spark）实现离线批处理分析，支持每日定时跑批。 **✅ 已完成**
3. **算法分析多样化**：提供技术指标（MA/MACD/KDJ/RSI/布林带）、缠论 6 步递归分解、量化策略回测等专业分析手段。 **✅ 已完成**
4. **后端服务标准化**：基于 Spring Boot 提供标准化 REST API，支持 JWT 认证、Redis 缓存、WebSocket 推送。 **✅ 已完成**
5. **前端交互现代化**：基于 Vue 3 SPA 实现丰富的金融数据可视化，提供股票浏览、基金查询、AI 对话等 18+ 功能页面。 **✅ 已完成**
6. **AI 智能分析**：基于多智能体架构（7 个专业化 Agent），调用大模型 API 进行基本面/技术面/情绪面综合分析，支持无 API Key 的模拟降级模式。 **✅ 已完成**
7. **一键容器化部署**：通过 Docker Compose 编排 18 个容器，实现全栈一键部署。 **✅ 已完成**

### 1.3 核心技术栈

| 层 | 技术 | 版本 |
|:---|:-----|:----:|
| 数据采集 | Python HTTP/TCP 直连 (7源, 16类型) | Python 3.11 |
| 大数据存储 | HDFS / Hive / MySQL 8.0 (23表) | Hadoop 3.2.1 / Hive 2.3.2 |
| 大数据计算 | PySpark 3.x (废弃 MapReduce) | Spark 3.5.0 |
| 算法分析 | Python 原生实现 (9指标+缠论+量化) | Python 3.11 |
| 后端 API | Java / Spring Boot 3 / MyBatis-Plus | Java 17 / **Spring Boot 3.x** ⚠️ |
| 前端 | Vue 3 / TypeScript / ECharts / Element Plus | Vue 3.4 |
| AI 服务 | Python FastAPI / DeepSeek / 多智能体 | FastAPI |
| 部署 | Docker Compose | 20+ |
| 缓存 | Redis | 7-alpine |

> ⚠️ **V2.0 修正**: 此前文档误标为 Spring Boot 2.7.18，实际代码为 Spring Boot 3.x（使用 jakarta.* 命名空间）。

## 3. 业务需求

### 3.1 BR1 — 实时行情监控

**描述**：用户能够实时查看 A 股行情数据，包括股票列表、个股详情、K 线走势、市场指数等。

**业务规则**：
- 股票数据来源于 6 个外部数据源的采集结果
- 前端数据经由 Redis 缓存加速（TTL=30 分钟）
- 个股行情延迟控制在秒级以内 ✅

### 3.2 BR2 — 技术指标分析

**描述**：用户能够对个股进行多种技术指标分析，辅助投资决策。

**覆盖指标**：
- 均线（MA5/10/20/60）及金叉/死叉检测 ✅
- MACD（EMA12/26 + DIF/DEA）及背离识别 ✅
- KDJ（K/D/J）及超买/超卖判断 ✅
- RSI（6/12/24）及 Wilders 平滑 ✅
- 布林带（中轨/上轨/下轨/带宽/%B） ✅
- **新增**: CCI 商品通道、WR 威廉指标、OBV 能量潮、成交量均线 ✅

**实现说明**：技术指标在 L3 (Python) 和 L6 前端 (TypeScript) 各有一份实现，算法一致。前端计算用于实时渲染，L3 计算用于批量分析和持久化。

### 3.3 BR3 — 缠论分析

**描述**：用户能够对个股进行缠论 6 步递归分解分析。

**分析流程**：
1. K 线包含处理 → 2. 分型识别（顶分型/底分型）→ 3. 笔识别（上升笔/下降笔）→ 4. 线段识别（至少 3 笔）→ 5. 中枢识别（ZG/ZD）→ 6. 买卖信号（三类买点/卖点）

**架构**：L3 Python 引擎计算 → L4 后端通过子进程调用 Python 桥接脚本 → L6 前端 ECharts 渲染。✅ 全部完成

### 3.4 BR4 — 量化策略回测

**描述**：用户能够基于历史数据对量化策略进行回测，评估策略表现。✅ 已完成

**策略类型**：
- 均线策略（金叉买入/死叉卖出）✅
- 动量策略（动量因子选股）✅
- 多因子策略（多因子评分选股）✅

**回测指标**：
- 总收益率、年化收益率、最大回撤、夏普比率、胜率

### 3.5 BR5 — 基金信息查询 ✅

**描述**：用户能够查询基金列表、详情、净值走势和持仓信息。

**数据类型**：基金列表、基金详情、基金净值历史、基金持仓

### 3.6 BR6 — 市场信号监控 ✅

**描述**：用户能够查看多种市场信号数据，捕捉投资机会。

**信号类型**：
- 题材归因（强势股热点题材）✅
- 龙虎榜数据 ✅
- 北向资金流向 ✅
- 限售解禁信息 ✅
- 行业对比分析 ✅
- **新增**: 个股资金流向（主力净流入/超大单/散户）✅

### 3.7 BR7 — AI 智能分析 ✅

**描述**：用户能够通过自然语言与 AI 进行对话，获取个股的综合分析报告。

**分析维度**：
- 基本面分析（PE/PB/市值/盈利能力）✅
- 技术面分析（K线/均线/MACD/RSI/KDJ/布林带）✅
- 市场情绪分析（题材热度/北向资金/主力资金）✅
- 新闻事件分析 ✅
- 研究员辩论（3 轮多 Agent 辩论）✅
- 交易决策（买入/卖出/持有 + 仓位/止损）✅
- 风险评估与审核 ✅

### 3.8 BR8 — 自选股管理 ✅

**描述**：用户能够添加/移除股票到自选列表，方便跟踪关注标的。

### 3.9 BR9 — 资讯信息查询 ✅（V2.0 新增）

**描述**：用户能够查询券商研报、个股新闻、财联社快讯、全球资讯、巨潮公告等资讯数据。

**数据类型**：
- 券商研报列表 + 评级 + EPS 预测 ✅
- 个股新闻 ✅
- 财联社分钟级快讯 ✅
- 全球财经资讯 ✅
- 巨潮公告 ✅
- 研报 PDF 下载 ✅

#### 9.3 网络拓扑 — V2.0 修正

**双网络隔离架构**（此前文档仅描述单网络）：

```
collector-net (172.20.0.0/24)          bigdata-net (172.19.0.0/24)
┌──────────────────────┐     ┌──────────────────────────────────┐
│ Zookeeper            │     │ HDFS (NameNode + 2xDataNode)     │
│ DataCollector ────Kafka(双网卡)────► Hive / Spark / MySQL      │
│ (CSV→共享卷)         │     │ Redis / Backend / AI / Frontend  │
└──────────────────────┘     │ Prometheus / Grafana            │
                              └──────────────────────────────────┘
```

**跨层数据流转**：
- Kafka 桥接：`collector-kafka:29092`（采集层）↔ `collector-kafka:39092`（大数据层）
- 共享卷桥接：`collector-data:/data/collector_output` → HDFS NameNode 只读挂载 → Hive 外部表
