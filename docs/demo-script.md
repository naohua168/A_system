# 演示脚本 — 基金股票智能分析系统

## 5 分钟完整演示流程

---

### 🎬 准备 (30 秒)

1. 确保 Docker 环境运行: `cd docker && docker-compose up -d`
2. 启动后端: `cd backend && mvn spring-boot:run`
3. 启动前端: `cd frontend && npm run dev`
4. 浏览器打开: **http://localhost:5173**

---

### 📌 第1步 — 首页大盘 (30 秒)

> 路径: `/home`

- **展示**: 大盘指数轮播 (上证/深证/创业板/科创50)
- **操作**: 
  - 点击左右箭头滑动指数卡片
  - 点击「管理指数」添加/删除指数
- **说明**: "这是东方财富风格的指数看板，支持自定义"

---

### 📌 第2步 — 板块云图 (30 秒)

> 路径: `/home` 下滑

- **展示**: 矩形树图展示行业板块涨跌
- **操作**: 点击板块 → 跳转板块详情
- **说明**: "绿色代表下跌，红色代表上涨，面积表示市值"

---

### 📌 第3步 — 股票列表 (1 分钟)

> 路径: `/stocks`

- **展示**: 股票列表页（搜索框 + 行业筛选 + 排序）
- **操作**:
  - 输入关键字搜索
  - 按行业/涨幅筛选
  - 点击行 → 跳转 K线图
- **说明**: "支持多条件筛选和分页，数据来自后端 API"

---

### 📌 第4步 — K线图 + 技术指标 (1 分钟)

> 路径: `/stock/000001`

- **展示**: 
  - K 线图 (含 MA/BOLL 叠加指标)
  - 底部 VOL/MACD/KDJ/RSI 切换
  - 缠论分析面板
- **操作**:
  - 切换周期 (5分/日K/周K/月K)
  - 开关 MA/BOLL 叠加
  - 切换底部指标 MACD→KDJ→RSI
  - 开关缠论开关显示分型/笔/中枢
  - 点击指标参数设置齿轮 ⚙️
- **说明**: "这是系统的核心页面，集成 K 线、5 大技术指标、缠论分析"

---

### 📌 第5步 — 缠论分析 (1 分钟)

> 路径: `/stock/000001` 下方缠论卡片

- **展示**:
  - 统计: 顶分型/底分型/笔/中枢计数
  - 中枢区间: ZG/ZD 数值
  - 买卖信号: 一/二/三类买点/卖点
  - 背驰判断
- **说明**: "基于缠中说禅理论，自动识别分型点、笔、中枢和买卖信号"

---

### 📌 第6步 — 基金详情 (30 秒)

> 路径: `/fund/000001`

- **展示**:
  - 净值卡片 (最新净值/累计净值/各阶段收益)
  - 净值走势图 (周期切换)
  - 基金档案
  - 前十大持仓 (进度条 + 点击跳转)
- **说明**: "基金详情页，蚂蚁财富风格"

---

### 📌 第7步 — 量化回测 (30 秒)

> 终端执行

```bash
cd analysis-algorithms
python -m quantitative.backtest --fast 5 --slow 20
```

- **展示**: 回测结果 (收益率/回撤/夏普比/胜率)
- **说明**: "均线策略回测引擎，支持自定义参数和回测周期"

---

### 🏁 收尾

> 总结

```
技术栈: Hadoop + Hive + Spark + Spring Boot + Vue 3 + ECharts
已实现: 多源数据采集 → 大数据存储/计算 → 后端 API → 前端展示
亮点  : 缠论分析 + 技术指标 + 量化回测 + 多数据源融合
```
