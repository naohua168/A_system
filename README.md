# A 股全栈量化复盘系统

> **一个面向个人投资者的 A 股市场收盘复盘与数据分析平台。**

基于腾讯财经公开 API，通过 Python 采集管道、Redis 缓存、Spring Boot 后端和 Vue 3 前端，构建了完整的数据采集→存储→展示闭环。聚焦**收盘后复盘场景**——交易时段仅更新新闻，15:00 收盘后自动全量刷新当日数据。

## 快速启动

### 前置条件
- Docker Engine ≥ 20.10
- Docker Compose v2+

### 启动全部服务
```powershell
cd docker
docker compose up -d
# → 前端 http://localhost:5173
# → 后端 http://localhost:8082
```

### 首次初始化数据
```powershell
# 收盘快照（行情+信号+锁解+排行）
docker exec data-collector python3 /app/auto_seed.py
# K 线采集
docker exec data-collector python3 /app/seed_kline.py
# 涨跌排行
docker exec data-collector python3 /app/seed_analysis.py
```

### 日常使用

系统是**全自动的**——无需任何人工操作：

| 时段 | 行为 |
|:-----|:------|
| 交易日 09:00~15:00 | 展示上一个交易日快照，仅新闻实时更新 |
| 交易日 15:00+ | 自动触发 `data_rollover()` 全量更新 → 刷新页面查看当日数据 |
| 非交易日 | 展示最近交易日数据 |

## 数据流

```
交易日 09:00~15:00
  run_collector 循环 (每5min)
    ├── 财经资讯 ← API (唯一实时更新的数据)
    └── 前端标签: "交易时段 · 展示上一个交易日数据"

交易日 15:00 触发
  data_rollover() (每天一次)
    ├── Step 1: 行情冻结 → stock_basic / index_list (Redis)
    ├── Step 2: 信号采集 → 北向/热点/龙虎榜/行业/锁解/排行 (Redis)
    ├── Step 3: K线刷新 + 指数重建 (Redis)
    └── Step 4: MySQL 归档 (7张表, 每日快照)
```

## 设计决策

| 决策 | 原因 |
|:-----|:------|
| **纯缓存架构** | Redis 全量存储 + TTL，MySQL 仅作历史归档。启动快，部署简单 |
| **Python socket 直写 Redis** | 零外部依赖，数据采集器只依赖 Python 标准库，无 Redis-py/akshare 等 |
| **纯复盘模式** | 盘中仅展示昨日数据，收盘后一次性全量更新。避免盘中频繁采集被 API 限流 |
| **camelCase 统一** | Redis JSON 全部使用 camelCase，前端直接消费，无需映射层 |
| **缠论纯 Python 实现** | 无第三方缠论库依赖，可在无网络环境运行 |
