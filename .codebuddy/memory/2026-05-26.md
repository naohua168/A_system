### 1. 行业数据修复 (✅ 已完成)
- **问题**: 5,542/5,544 只股票的 industry 列被错误地填入数值（市值、涨跌幅），而非中文行业名
- **方案**: 引用 `a-stock-data` 库 (https://github.com/simonlin1212/a-stock-data.git) 的数据采集思路

- **最终方案**: 使用 `mootdx.F10(symbol=code, name='公司概况')` 提取"行业类别"字段
- **结果**: 1,176 → **5,542/5,544** 只正确 (99.96%)，仅2只退市股无法获取
- **核心脚本**: `scripts/fix_industry_mootdx.py`
- **数据格式**: `一级行业-二级行业-三级行业` (如 "银行-股份制银行Ⅱ-股份制银行Ⅲ")

## 关键技术发现
- **mootdx TCP直连** 是公司防火墙环境下唯一稳定的数据源
- **东财 push2 API** 仅在Docker容器内短暂可用，很快被封
- **a-stock-data V3.0** 移除了akshare，全部直连HTTP API
- MySQL容器偶尔会退出，需手动 `docker start mysql`
- **同花顺热点API** (`zx.10jqka.com.cn`) 零鉴权，73ms响应，历史数据可回溯至4月
